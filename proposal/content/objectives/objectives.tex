\section{Problem Definition}
\label{sec:problem}

Let $D$ be a corpus, $\phi$ an embedding onto the unit sphere and $\dist(x,y)=1-\langle\phi(x),\phi(y)\rangle$ the cosine distance. A query $q$ has a target document $\GT(q)\in D$. A cheap \emph{surrogate} $f'(d)=\dist(q,d)$ and an expensive \emph{judge} $J(q,d)\in\{0.1,\dots,1.0\}$, which costs one LLM call, are available. A \emph{search policy} $\pi$ holds the judged history $H_t=\{(d_i,J(q,d_i))\}_{i\le t}$ and chooses the next document to judge, $d_{t+1}=\pi(q,H_t)$: given the documents scored so far, \emph{which document should the LLM check next?} The main metric is the \textbf{cost to find the target} $N_\pi(q)$, the number of judge calls until $\GT(q)$ is judged. Secondary metrics are success within a budget and the accuracy of the returned document. A fixed ranking function $f$ yields a static best-first policy whose cost is the target's rank. The standard retriever is $f=\dist(q,\cdot)$, which we call \textbf{B1}. Since $J$ is pre-computed for all query--document pairs, any policy can be replayed offline at no LLM cost.

\section{Research Objectives}

The objective is to develop judge-guided search policies that find the target with fewer LLM calls than B1, especially where B1 fails, and to explain their behaviour through the geometry of the embedding space. \textbf{RQ1:} How reliable is the judge as a proximity signal, and how can ties at its top score be broken? \textbf{RQ2:} Which geometric properties explain retrieval failures? \textbf{RQ3:} Can policies that exploit judge feedback and geometry, invoked only when failure is likely, beat B1's cost? \textbf{RQ4:} Do the findings generalise across embedders, judges and datasets, and improve end-to-end RAG?

\paragraph{Hypotheses.}
\textbf{H1} Queries lie further from documents than documents from each other (supported). \textbf{H2} It is best to search mostly by distance to the query and a little by distance to the centroid of relevant documents (marginal gain only). \textbf{H3} Judge scores fall monotonically with distance to the target (supported, with ties). \textbf{H4} A \emph{negative} weight on the centroid of relevant-but-non-target documents lowers the cost on failed queries. \textbf{H5} Starting the search only when the first document is not the target preserves B1's cost on easy queries. \textbf{H6} Trilateration from calibrated, finer-grained judge scores localises the target better than any single anchor.
